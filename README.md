# ESILV_Python
Projet final python A3

## Objectif
Ce projet est un système d'analyse des avis et alertes de l'ANSSI, en se focalisant sur les CVE. De cette manipulation et complétion de données, nous envoyons des notifications auprès d'email concernés.
De plus, il est accompagné d'un notebook de représentation graphique des données.
